L1 против L2

Лекция 4, 0:33–0:47. Ищем веса с наименьшей ошибкой, но не выходя за допустимую область: ромб $|w_1| + |w_2| \le C$ для L1 и круг $w_1^2 + w_2^2 \le C^2$ для L2. Перетащи синюю точку (решение без регуляризации) и посмотри, когда L1 делает вес ровно нулём.

L1 (Lasso): ромб

L2 (Ridge): круг

Красная кривая — линия уровня ошибки, которая первой касается области. Точка касания — решение с регуляризацией. У ромба углы лежат на осях, поэтому касание углом обнуляет один вес. У круга углов нет, и касание на оси бывает только случайно.

Один вес: почему L1 даёт ровно ноль

Пусть без регуляризации лучший вес равен $w_0$, а ошибка вокруг него $(w - w_0)^2$. Добавляем штраф и ищем минимум:

$$\text{L2: } w^* = \frac{w_0}{1 + \alpha} \qquad\qquad \text{L1: } w^* = \operatorname{sign}(w_0)\cdot\max\big(|w_0| - \tfrac{\alpha}{2},\ 0\big)$$

вес $w^*$что произошло
без регуляризации—

L1 (Lasso)

L1 вычитает из веса постоянные $\alpha/2$ и останавливается в нуле: все веса с $|w_0| \le \alpha/2$ выключаются. L2 делит вес на $1 + \alpha$, и ноль не получается никогда. Зато большой вес L1 сжимает слабее: при $w_0 = 2$, $\alpha = 1$ L1 даёт $1.5$, а L2 — $1.0$.
