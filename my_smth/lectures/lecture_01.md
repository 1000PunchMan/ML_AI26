### 7 ключевых идей

1. **ML = модель сама выводит правила из данных**, а не программист пишет `if-else`. Нужны данные с известными ответами.
2. **Модель — это формула с неизвестными параметрами.** Никакого «чёрного ящика»: для линейной регрессии это просто взвешенная сумма признаков.
3. **Обучение — это подбор параметров, при которых функция потерь минимальна.** «Модель нашла закономерности» на языке математики = «нашли такие $w$, при которых ошибка на обучающих данных минимальна».
4. **Функция потерь (loss) и метрика качества — разные вещи.** Loss удобен для оптимизации, метрика понятна людям и отражает бизнес-цель.
5. **Качество оцениваем только на данных, которые модель не видела** (train/test split, а лучше кросс-валидация).
6. **Сначала смотрим на данные (EDA), потом обучаем.** Ошибки → в NaN → заполнить медианой. «Выбросы» с боксплота **не удалять**.
7. **Модель — лишь один кубик проекта.** Есть ещё сбор данных, A/B-тест, внедрение, мониторинг.

### Главные формулы

**Линейная регрессия** (прогноз стоимости дома по площади $x_1$ и числу комнат $x_2$):

$$a(x) = w_0 + w_1 x_1 + w_2 x_2$$

В общем случае для $d$ признаков:

$$a(x) = w_0 + \sum_{j=1}^{d} w_j x_j \qquad (\text{параметров: } d + 1)$$

**Функция потерь MSE** ($\ell$ — число объектов в выборке):

$$Q(w) = \frac{1}{\ell}\sum_{i=1}^{\ell}\big(y_i - a(x_i)\big)^2$$

**Обучение** — найти веса, минимизирующие потери:

$$w^{*} = \arg\min_{w} Q(w)$$

**Метрики:**

$$\text{RMSE} = \sqrt{\text{MSE}}, \qquad \text{accuracy} = \frac{\#\{\text{верных ответов}\}}{\#\{\text{всех объектов}\}}$$

**Масштабирование признаков:**

$$\text{StandardScaler:}\ \ x' = \frac{x - \mu}{\sigma}, \qquad \text{MinMaxScaler:}\ \ x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$

**Усы боксплота** ($Q_1, Q_3$ — квартили, $\text{IQR} = Q_3 - Q_1$):

$$[\,Q_1 - 1.5\cdot\text{IQR},\ \ Q_3 + 1.5\cdot\text{IQR}\,]$$

### Словарик

| Термин | Что значит |
|---|---|
| Объект | То, про что делаем прогноз (клиент, дом, пациент) |
| Признак (feature) | Числовая (или нет) характеристика объекта: возраст, площадь… |
| Целевая переменная (target), $y$ | То, что предсказываем |
| Матрица объект-признак $X$ | Строки = объекты, столбцы = признаки. Размер $\ell \times d$ |
| Классификация | $y$ из **конечного** набора заранее известных классов (вернёт / не вернёт) |
| Регрессия | $y$ — число, **упорядоченное**, бесконечно много значений |
| Кластеризация | Целевой переменной нет; группируем похожие объекты |
| Supervised / Unsupervised | С учителем (есть $y$) / без учителя (нет $y$) |
| Веса $w$, bias $w_0$ | Параметры модели; $w_0$ — свободный член (смещение) |
| Loss / функция потерь / функционал ошибки | То, что минимизируем при обучении |
| Метрика качества | То, чем оцениваем готовую модель |
| Train / test | Часть данных для обучения / для честной оценки |
| Кросс-валидация (K-fold) | $K$ раз обучаем на $K-1$ частях, проверяем на оставшейся, усредняем |
| EDA | Разведочный анализ данных: смотрим и чистим данные до обучения |
| `random_state` / seed | Фиксация случайности → воспроизводимость |
| Препрод / A/B-тест | Проверка модели на реальных пользователях |
| Мониторинг, data drift | Слежение за моделью в проде; изменение данных со временем |

### ⚠️ Нюансы, где лектор упростила (чтобы не запутаться)

- **«Корреляция ≈ 0 со всеми признаками → ML не сработает».** Коэффициент Пирсона ловит только **линейную** связь. Если $y = x^2$ и $x$ симметричен вокруг нуля, корреляция ≈ 0, но зависимость идеальная. Нелинейная модель (дерево, бустинг) её найдёт. Лектор сама потом приводит пример «серый + 20 тонн», где признаки полезны только вместе.
- **«Масштабирование не влияет на линейную регрессию».** Верно для обычной регрессии (МНК). С регуляризацией (L1/L2 — будет дальше в курсе) масштаб уже влияет: она сама об этом намекает на 1:59:50.
- **«Несколько целевых переменных — multi-label».** Для регрессии корректнее *multi-output / multi-target regression*. «Multi-label» — термин из классификации (объекту можно присвоить несколько меток сразу).
- **«За усами не больше 0,1% данных при нормальном распределении».** На самом деле ≈ 0,7% (усы ≈ $\mu \pm 2.7\sigma$). Главная мысль от этого не меняется.

## 4. Где это в проде

- **Скоринг, отток, рекомендации** — классические supervised-задачи; в банках скоринг автоматизирован целиком.
- **Loss ≠ метрика** встречается везде: LLM обучают на кросс-энтропии (loss), а оценивают бенчмарками, человеческими оценками, бизнес-метриками.
- **Offline-метрики врут** — поэтому A/B-тесты. Рекомендательная система с отличным offline-качеством может не поднять продажи.
- **Мониторинг и data drift** — модель в проде деградирует со временем; без графиков вы об этом не узнаете.
- **Пропуски в проде неизбежны** — поэтому их *заполняют*, а не удаляют: модель обязана отработать на клиенте, у которого не заполнено поле.
- **Утечка данных:** медиану для заполнения и параметры скейлера правильно считать **только на train** и применять к test (в sklearn — через `Pipeline`). В лекции это пока не обсуждалось, но в реальной работе это частая ошибка.

## 5. Самопроверка

<details><summary>1. Чем ML отличается от классического программирования? Когда ML не нужен?</summary>

В ML правила выводятся из размеченных данных, а не пишутся вручную. Не нужен, если: есть точная формула ($m = \rho V$, платёж по кредиту); данных нет или их очень мало; нужна 100% точность; в данных нет зависимости $y$ от признаков.
</details>

<details><summary>2. Почему X — матрица, а y — вектор?</summary>

У каждого объекта много признаков (строка матрицы), а ответ один — одно число.
</details>

<details><summary>3. Прогноз оценки за курс по 10-балльной шкале — классификация или регрессия?</summary>

Лучше регрессия: оценки упорядочены (6 > 5). Классификатор считает классы «3» и «9» никак не связанными и может быть одинаково уверен в обоих. Регрессия выдаст 7.89, потом округлим.
</details>

<details><summary>4. Сколько параметров у линейной регрессии с 10 признаками? Что в ней неизвестно на обучении?</summary>

11 ($w_0,\dots,w_{10}$). Известны $X$ и $y$, неизвестны только веса.
</details>

<details><summary>5. Зачем в MSE квадрат?</summary>

Иначе ошибки $+10$ и $-10$ скомпенсируют друг друга, и плохая модель получит маленькую ошибку. (Ответ уровня «мидл+» лектор обещала на следующей неделе.)
</details>

<details><summary>6. MSE = 1 000 000 (цены в рублях). Модель хорошая?</summary>

Да: $\sqrt{10^6} = 1000$ рублей ошибки на дом — это ничто. MSE измеряется в «рублях²», поэтому её трудно интерпретировать → используем RMSE.
</details>

<details><summary>7. Почему оптимизируем loss, а не сразу метрику?</summary>

К loss есть требования (желательно гладкая, удобная для оптимизации, лучше с одним минимумом), а метрика может быть любой формулой — например, accuracy ступенчатая, её не оптимизировать градиентами.
</details>

<details><summary>8. Почему качество нельзя оценивать на train? Зачем кросс-валидация?</summary>

Модель уже видела ответы → оценка будет завышенной. Одно разбиение train/test случайно (R² скакал 0.43 → 0.51 → 0.48), кросс-валидация усредняет по $K$ разбиениям → устойчивее.
</details>

<details><summary>9. Правильный порядок обработки пропусков и ошибок? Почему медиана?</summary>

Ошибки (возраст 510) → NaN → заполнить медианой. Среднее чувствительно к выбросам: 5 ошибок из 442 сдвинули среднее с 26.4 до 27.
</details>

<details><summary>10. На боксплоте после чистки остались точки за усами. Что с ними делать?</summary>

Ничего. Это не ошибки, а реальные объекты (человеку 81 год при усе 80). Удаление или клиппинг искусственно «очистит» датасет, и в проде модель будет работать хуже.
</details>

<details><summary>11. Зачем масштабировать признаки для линейной регрессии, если качество не меняется?</summary>

Чтобы сравнивать веса между собой: после масштабирования $|w_j|$ показывает важность признака. До масштабирования в весе «сидит» масштаб признака.
</details>

<details><summary>12. Две строки с одинаковыми признаками, но разным y — дубликат?</summary>

Нет — это нормальная ситуация (одинаковые дома могут стоить по-разному), оставляем. Удаляем только полные дубликаты строк: они увеличивают вес объекта (на семинаре 30 копий одной строки подняли MSE с 2893 до 3580).
</details>
